# 06: 构建失败只标高风险

**What to build:** 分支构建变红时，只有"从未被任何成功构建包含过"的卡才标红「构建失败 #N」并可点击直达；曾经成功过的卡不标。详情注明本次构建新引入的合入数量，并明确写出"不断定是它引起的"。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 该卡曾被更早的成功构建包含过 → 构建失败**不**上卡面
- [ ] 从未成功过且最新已完成构建为 FAILURE → 卡面红字「构建失败 #N」，可点开 Jenkins
- [ ] 详情写明"本次构建新引入的合入共 N 个"，并注明不断定因果
- [ ] 单测覆盖两种分支：曾成功过、从未成功过
- [ ] 分支整体变红时，不会出现"几乎所有卡都标红"
