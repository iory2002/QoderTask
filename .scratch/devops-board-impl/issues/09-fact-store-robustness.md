# 09: 库的健壮性：迁移、损坏重建、只读降级

**What to build:** 库需要升级、损坏、或被更高版本写过时，扩展都不崩：迁移前先备份、失败能回滚；库损坏时改名重建并明确告知历史已重置；库版本高于代码时进入只读模式而不是硬写。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] `user_version` 迁移按顺序执行，每个迁移一个事务；迁移前生成备份，失败则回滚
- [ ] 打开失败或完整性检查不通过 → 把原库改名为带时间戳的损坏文件、重建空库，并在板内提示"历史已重置"
- [ ] 库版本高于代码版本 → 只读模式 + 提示"库来自更新版本"，不尝试降级迁移
- [ ] 只读模式下功能仍可用（退回单窗口直连，见 10）
- [ ] 单测覆盖三条路径：正常迁移、损坏重建、高版本只读
