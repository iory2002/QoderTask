# 08: 单卡写回 Jira

**What to build:** 拖下去之后弹出确认表单，字段已经按这张卡当前的值填好，一路确认就能把状态真的改到 Jira 里。遇到插件填不了的字段，就明确让你去 Jira 完成，而不是发一个注定失败的请求。

**Blocked by:** 07

**Status:** ready-for-agent

- [ ] 表单字段来自这张卡当前可用的动作，值按 issue 现有字段预填（不改就无需填写）
- [ ] 只提交用户改动过的字段，未改动的不进请求
- [ ] 支持单行/多行文本、单选、多选、人员四类控件
- [ ] 遇到插件不支持的字段类型时，列出字段名、禁用提交、并给出「在 Jira 中完成」的链接
- [ ] 必填项为空时提交按钮不可用
- [ ] Jira 返回字段级错误时，错误显示在对应控件旁，不是笼统的「保存失败」
- [ ] 写成功后卡片出现在目标列，浮层关闭，状态与 Jira 一致
- [ ] 写失败时卡片不移动，错误原因可读
