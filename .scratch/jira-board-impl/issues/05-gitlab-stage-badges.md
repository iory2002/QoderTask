# 05: GitLab 阶段徽章

**What to build:** NEX2 与 NEX 的卡片上出现交付阶段徽章：这张卡的代码走到哪一步了（没交 / 待审 / 已批准 / 已合入）。没接入代码托管的项目不出徽章，取数失败时显示「无法判定」而不是「未提交」。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 有已合入 MR 的 issue 显示「已合入」（可用 NEX2-932 验证：它有三个 MR，应指向最近合入的那个）
- [ ] MR 已开且确实已批准时显示「已 Approve 待合入」；只有人按过 Approve 但 MR 仍未批准的，**不得**显示为已批准
- [ ] MR 已开且未批准显示「MR 待审」
- [ ] 关联不到任何 MR 显示「未提交」
- [ ] GitLab 不可达或凭据失效时显示「无法判定」，并在顶部给出可解释的提示
- [ ] MAGR3 / IB 的卡片不出现阶段徽章
- [ ] 标题写作 `NEX2-1038+1039` 时，两张卡都能被关联上（不是只关联第一个）
- [ ] 形如 `C1-6`、`L3-12` 的串不会被误认为 Jira key
- [ ] 阶段判定逻辑有单元测试覆盖六种状态（含多 MR 取最高、批准失效的边界）
