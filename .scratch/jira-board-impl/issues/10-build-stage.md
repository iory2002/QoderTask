# 10: 构建阶段

**What to build:** 合入之后还能再往前走一格：这张卡的合入有没有被构建过、构建成功还是失败、是哪一次构建、什么时候。因为构建一天只跑两次、一次跑几小时，界面上必须能看出「这个结论有多旧」。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] NEX2 与 NEX 的卡片，合入后有更晚的成功构建时，显示「已构建」并给出构建号与构建时间
- [ ] 只有更早的构建时不显示已构建，停在「已合入待构建」
- [ ] 构建正在进行中时既不算成功也不算失败
- [ ] 构建失败时挂出可见的失败标记，同时阶段仍停在「已合入待构建」
- [ ] 两条链路的 job 都能正确定位（NEX2 走 7.10.x 分支、NEX 走 5.10.x 分支）
- [ ] 内网 Jenkins 的自签证书下能正常取数
- [ ] 详情浮层补上构建号、构建的绝对时间、构建所在分支
- [ ] 没有配置构建通道的项目不出构建相关徽章，也不出现「待构建」字样
