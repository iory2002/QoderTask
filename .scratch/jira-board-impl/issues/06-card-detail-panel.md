# 06: 详情浮层（只读）

**What to build:** 点一张卡片，右侧滑出它的交付事实：命中哪个 MR、谁批的、什么时候合的、这个徽章是按哪条规则算出来的。徽章从此有出处，误判能自己看穿。

**Blocked by:** 05

**Status:** ready-for-agent

- [ ] 点卡片打开浮层，Esc 或点空白处关闭
- [ ] 浮层显示关联 MR 的编号、状态、批准人、合入时间，以及「是靠标题还是靠分支名关联上的」
- [ ] 浮层说明当前阶段的推导依据（命中了哪一条判定规则）
- [ ] 同一个 issue 有多个 MR 时全部列出，默认高亮卡片上展示的那个
- [ ] 有关联不到 MR / 数据缺失的情况，浮层明确写出「为什么无法判定」
- [ ] 「在 Jira 中打开」用外部浏览器打开，不在 IDE 内跳转
- [ ] 浮层内容随轮询更新，但不会在用户读的时候把焦点抢走
