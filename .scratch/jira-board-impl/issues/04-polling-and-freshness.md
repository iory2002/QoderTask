# 04: 轮询与新鲜度

**What to build:** 看板自己能保持新鲜：定时重拉，但数据没变时画面不闪；网络出问题时告诉你「看到的是什么时候的数据」，而不是假装一切正常。

**Blocked by:** 03

**Status:** ready-for-agent

- [ ] 每隔设定的秒数自动刷新一次，刷新期间界面可交互
- [ ] 刷新回来的数据与上一次完全一致时，界面不发生重绘（不闪、不丢滚动位置、不丢选中状态）
- [ ] 上一轮请求还没返回时，不发下一轮（不叠加请求）
- [ ] 请求超时或失败时，保留上一次成功的数据，并标注「数据可能过期 · 时间」
- [ ] 网络恢复后无需手动操作即可回到正常态，过期标注消失
- [ ] tab 不在前台时暂停或降频轮询，回到前台立即刷新一次
