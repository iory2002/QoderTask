# 09: 软闸门与乐观更新

**What to build:** 拖下去立刻有反馈（不等三秒），但过程中能看出「正在提交」；失败会自己弹回来并说明原因。阶段没达标就往 In Test 拖时，先亮出缺什么再由你决定。

**Blocked by:** 08, 05

**Status:** ready-for-agent

- [ ] 拖下后卡片立即出现在目标列，带「提交中」的视觉标记
- [ ] 提交成功后标记消失，卡片保持在新列
- [ ] 提交失败后卡片自动弹回原列，并显示可读的失败原因
- [ ] 提交中的那张卡不被轮询刷新覆盖（不会先跳到新列又跳回旧列再跳回新列）
- [ ] 阶段未达标时拖入 In Test 会弹出软闸门，逐条列出缺什么（例如「未见合入记录」「构建未通过」）
- [ ] 软闸门选择取消 → 不写 Jira；选择仍然推进 → 正常写入
- [ ] 阶段已达标时不弹闸门，直接进表单
